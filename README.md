## 📖 Project Description
This project analyzes beverage sales data across multiple brands, states, and months using **Power BI**, **Power Query**, and **Excel formulas**.  
The dataset includes retailer information, beverage brands, monthly sales, units sold, and revenue.  
Raw data was cleaned, transformed, and normalized with **Power Query** before being modeled and visualized in Power BI.  

The dashboard provides interactive insights into sales performance by month, state, and brand, helping identify revenue trends, seasonal peaks, and geographic opportunities.

---

## 🔑 Key Insights
- **Revenue Peaks:** December, July, and August recorded the highest monthly revenues.  
- **Top Brands:** Coca-Cola, Diet Coke, Sprite, and Fanta consistently drive strong sales.  
- **Geographic Trends:** Certain U.S. states outperform others in revenue contribution.  
- **KPIs:**  
  - Total Revenue: **1.13M**  
  - Units Sold: **2.04M**  
  - Average Price per Unit: **0.33–0.50**  

---

## 📂 Features
- Interactive **Power BI dashboard** with charts, maps, and KPIs  
- Monthly revenue trend analysis  
- State-level revenue distribution via geographic maps  
- Brand-level performance comparison  
- **Data cleaning with Power Query** (removing duplicates, handling missing values, normalizing formats)  
- **Formulas used:** SUMIFS, VLOOKUP, INDEX-MATCH, IFERROR for automated calculations  

---

## 🛠️ Tools & Techniques
- **Power BI** for visualization and dashboard creation  
- **Power Query** for ETL (Extract, Transform, Load) operations  
- **Excel formulas** for dynamic calculations and error handling  
- **Data modeling** for structured analysis across multiple dimensions (time, brand, geography)  

---

## 🚀 Recommendations
- Focus marketing efforts on **peak months (July, August, December)** to maximize revenue.  
- Strengthen distribution in **high-performing states** while identifying underperforming regions for growth.  
- Continue leveraging **top-selling brands** like Coca-Cola and Sprite while exploring opportunities for emerging products.
